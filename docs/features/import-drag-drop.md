# 导入与拖拽

LytVPK 支持通过上传按钮或拖拽导入文件。拖拽时可以把文件直接放到应用窗口里。

## 支持的内容

| 类型                  | 处理方式                                |
| --------------------- | --------------------------------------- |
| `.vpk`                | 复制到当前 `addons` 目录并刷新列表      |
| `.zip`、`.rar`、`.7z` | 解压其中的 VPK 文件到当前 `addons` 目录 |
| 文件夹                | 确认后批量导入已有 VPK 或打包 Mod 资源  |
| `.mdmp`、`.dmp`       | 打开崩溃转储查看器                      |
| 图片、GIF、TGA        | 打开喷漆制作工具                        |

导入 VPK、压缩包或文件夹前，需要先选择 `addons` 目录。

## 使用上传按钮

点击 MOD 管理页的上传按钮，选择要导入的文件。这个方式适合从文件选择器里挑选一个或多个文件。

上传按钮会复用和拖拽相同的导入流程。

## 使用拖拽

把文件或文件夹拖进应用窗口。文件夹会先扫描，再等待确认。

拖拽时会显示导入进度面板，包括：

- 当前处理的文件。
- 复制、解压或打包阶段。
- 总进度。
- 成功和失败结果。

如果压缩包里有多个 VPK，应用会尽量并行解压，并在完成后刷新列表。

## 拖入文件夹

先在 MOD 管理页选择要安装到的 `addons` 目录，再把文件夹拖进应用窗口。应用在后台递归查找文件夹及其子目录中的 `.vpk` 文件，扩展名不区分大小写。指向目录外的符号链接和 Windows 目录联接会被跳过。

- 找到已有 VPK 且根目录没有 Mod 资源结构时，确认窗口会列出文件的相对路径。点击“确认导入”开始逐个导入，也可以点击“取消”。
- 文件夹根目录包含 `materials`、`models`、`scripts` 等 Mod 资源结构，且未找到已有 VPK 时，点击“确认打包”将资源打包并放入选中的 `addons` 目录，也可以点击“取消”。
- 同时找到已有 VPK 和 Mod 资源结构时，确认窗口也会列出找到的 VPK。选择“打包资源目录”会排除已有 VPK 及其配套文件，选择“导入其中的 VPK”会逐个导入列出的文件，也可以点击“取消”。
- 文件夹没有可识别的内容或扫描失败时，应用会显示提示。

一次拖入多个项目时，取消只会影响当前确认的文件夹。

### 导入 VPK 的配套文件

从文件夹导入 VPK 时，应用还会复制与该 VPK 位于同一目录且主文件名相同的 `.meta`、`.jpg`、`.jpeg`、`.png` 和 `.gif` 文件。匹配时，主文件名和扩展名均不区分大小写。复制后的配套文件沿用已导入 VPK 的主文件名，并使用小写扩展名。

目标目录已存在同名 VPK 时，应用会跳过该 VPK 及其配套文件。VPK 导入成功后，应用会逐个跳过与目标目录内文件同名的配套文件，并继续复制其余配套文件。同名冲突也包括仅大小写不同的文件名。导入结果会显示跳过的 VPK 和发生同名冲突的配套文件。

## 喷漆素材拖拽

拖入图片、GIF 或 TGA 时，不会安装到 `addons`，而是打开喷漆制作工具。你可以在工具里预览、调整尺寸和格式，再保存为 VTF/VMT。

## 常见问题

### 导入失败怎么办？

常见失败原因包括：

- 尚未选择 `addons` 目录。
- 文件格式不支持。
- 压缩包里没有可用的 VPK 文件。
- 目标目录没有写入权限。
- 游戏或其他程序正在占用目标文件。

失败后可以查看导入面板中的失败信息，再重新拖入或手动处理文件。

如果是压缩包导入失败，可以先手动解压，确认里面是否有可用的 `.vpk` 文件。
