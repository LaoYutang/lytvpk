# 设置

“设置”页面分为网络设置、界面设置、工坊设置和存储设置。

## 网络设置

### 网络加速

网络加速用于创意工坊图片和文件下载。

可选模式：

- 自动优选最佳 IP：应用自动选择推荐线路。
- 手动指定 IP：从候选列表选择，或填写自建加速 IP。

如果当前网络访问 Steam CDN 正常，可以保持默认；如果图片加载慢或下载慢，可以尝试开启。

### 工坊 DNS

当工坊列表、详情无法加载，或工坊链接解析失败时，可以尝试更换工坊 DNS。

打开“设置” → “网络设置”，在“工坊 DNS”中选择：

- 腾讯 DNS：`119.29.29.29`，默认选项。
- 阿里 DNS：`223.5.5.5`。
- 自定义 DNS：填写一个 IPv4 或 IPv6 地址，例如 `119.29.29.29`。不要填写网址、域名、端口或多个地址。
- 使用系统 DNS：使用当前 Windows 网络的 DNS 设置。

选好后点击“保存”。保存成功后，下次联网加载工坊列表、详情或解析链接时会使用新的设置，无需重启软件。已经显示的内容不会自动刷新。

如果所选 DNS 不可用，相关操作会提示失败，不会自动切换到其他 DNS。可以手动更换选项，保存后再试。

工坊 DNS 只影响软件内的工坊数据访问，不会更改 Windows 的 DNS 设置。图片加载和 Mod 文件下载仍使用“网络加速”设置。更换 DNS 可以帮助解决域名解析问题，但无法解决所有网络故障或线路拥堵。

## 界面设置

界面设置用于调整 MOD 管理页的使用习惯。

- 显示模式：列表或卡片。
- 框选模式：拖拽绘制选择框来批量选择文件。
- Ctrl+单击选择：按住 Ctrl 点选多个 Mod。
- 筛选布局：简洁模式节省空间，经典模式展开更多筛选项。

## 工坊数据

“开启工坊信息存储”会为工坊文件创建 `.meta` 信息，用于保存名称、作者等数据。

开启后可以使用 Mod 更新检测。更新检测会检查带有工坊信息的 Mod 是否存在新版本。

## 工坊浏览器跳转

“跳转目标”决定在工坊详情里点击“使用浏览器打开”时打开哪里：

- 镜像站 `l4d2ws.com`。
- Steam 官方工坊。

## 描述翻译

描述翻译用于创意工坊详情页。支持：

- 微软。
- Yandex。
- 自定义 AI。

使用自定义 AI 时，需要填写 Base URL、API Key 和模型 ID。

## 存储设置

“存储设置”用于调整 Mod 快照的保存位置。

- 选择目录：把之后的快照保存到指定位置。
- 迁移已有快照：更换位置时，把已有快照一并移动到新目录。
- 仅用于后续快照：保留已有快照的旧位置，只让之后创建的快照使用新目录。
- 恢复默认：重新使用应用默认的快照目录。
- 打开文件夹：在资源管理器中打开当前快照目录。

完整备份可能占用较多空间，建议选择剩余空间充足的位置。快照目录不能设置在 `addons`、`disabled` 或 `workshop` 中。
