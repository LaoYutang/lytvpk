# Mod 快照

“Mod 快照”用于保存某一时刻的 Mod 启用状态、加载顺序，或者制作可以恢复文件内容的完整备份。适合在批量启用或禁用、整理文件、更新 Mod、删除文件前留下可恢复的状态。

快照只保存在本机，不会上传到网络。

## 两种类型

| 类型 | 记录内容 | 特点 | 适用场景 |
| --- | --- | --- | --- |
| 文件名快照 | 记录 `addons` 根目录中的 VPK 文件名和 `addonlist.txt` | 创建快、占用小，不保存 VPK 文件内容 | 批量启用、禁用或临时调整前保存当前状态 |
| 完整备份 | 打包 `addons` 根目录中的 VPK、同名预览图、`.meta` 文件和 `addonlist.txt` | 可以恢复文件内容，占用更大、耗时更长 | 更新、删除、重命名或集中整理前备份 |

文件名快照不能找回已经删除或重命名的 VPK 内容。如果文件仍保留在 `addons` 或 `disabled` 中，可以根据文件名恢复启用状态。

## 创建快照

1. 打开“工具箱”。
2. 在“Mod 快照”卡片中点击“打开快照工具”。
3. 点击“新建快照”。
4. 选择“文件名快照”或“完整备份”。
5. 填写容易识别的名称，例如“写实模式启用状态”或“更新人物 Mod 前”。
6. 点击“创建快照”，等待创建完成。

完整备份会读取并压缩所选文件，文件较多时需要更长时间。创建期间请勿关闭窗口。

如果应用提示 `workshop` 目录中有文件不在快照范围内，而这些文件也需要备份，请先把它们转移到 `addons` 根目录，再创建完整备份。

## 管理快照

快照列表按创建时间从新到旧排列，并显示类型、时间、Mod 数量和占用空间。

- 搜索：按名称快速查找快照。
- 恢复：打开恢复预览，确认后把 Mod 状态恢复为快照记录的状态。
- 重命名：修改快照名称，方便以后识别。
- 删除：把快照移到回收站。删除快照不会影响 `addons` 中的 Mod。
- 打开存储位置：在资源管理器中打开当前快照目录。

## 恢复快照

1. 关闭 Left 4 Dead 2。
2. 在快照列表中找到需要的快照，点击“恢复”。
3. 等待恢复预览生成。
4. 检查“恢复计划”中的启用、禁用、新增、覆盖、缺失和跳过项。
5. 确认计划符合预期后，点击“确认并执行恢复”。

生成恢复预览只会读取当前文件，不会立即修改 Mod。只有点击“确认并执行恢复”后，应用才会按预览计划执行。

恢复计划中的常见标记：

- 启用：把仍存在于 `disabled` 中的同名 Mod 恢复到根目录。
- 禁用：把快照之后新增、且不在快照中的 Mod 移到 `disabled`。
- 新增：从完整备份中恢复当前缺失的文件。
- 覆盖：使用快照中的文件内容覆盖当前版本。
- 清理：清理根目录中与 `disabled` 内容相同的重复副本。
- 缺失：快照中有记录，但当前 `addons` 和 `disabled` 中都没有找到文件。
- 跳过：当前状态已经与快照一致，不需要改动。
- 列表：恢复 `addonlist.txt` 中保存的加载顺序和启用状态。

如果恢复计划显示“无法执行恢复”，请先处理提示中的问题。游戏正在运行、问题 Mod 查找仍在进行，或快照文件不完整时，恢复会被阻止。预览后如果 Mod 目录又发生了变化，应用也会要求重新生成预览。

## 重要说明

- 快照扫描范围是 `addons` 根目录，不包含 `workshop` 目录。
- `disabled` 目录不会作为独立备份对象。文件名快照可以借助 `disabled` 中的同名文件恢复启用状态；完整备份用于恢复快照创建时位于 `addons` 根目录中的文件。
- 恢复会把当前 Mod 调整回快照状态，因此快照之后新增的 Mod 可能被移动到 `disabled`，内容不同的文件也可能被覆盖。
- 如果当前状态也需要保留，建议在执行恢复前先创建一份完整备份。
- 从另一套 `addons` 目录制作的快照，恢复时会按当前目录中的文件名匹配。执行前请认真检查恢复预览。
- 损坏或文件不完整的快照无法恢复，可以重命名后保留，也可以直接删除。

## 存储位置

快照默认保存在应用配置目录中，也可以在“设置 → 存储设置 → Mod 快照”中改到空间充足的位置。

- 选择目录：设置新的快照存储位置。
- 迁移已有快照：把原位置中的快照移动到新位置。
- 仅用于后续快照：保留原位置的快照，之后创建的快照保存到新位置。
- 恢复默认：重新使用应用默认的快照目录。
- 打开文件夹：直接打开当前快照存储位置。

不要把快照目录设置在 `addons`、`disabled` 或 `workshop` 中。

## 使用建议

- 准备批量启用或禁用 Mod 时，先创建文件名快照，方便快速恢复原来的状态。
- 准备批量更新、删除、重命名或整理 Mod 时，先创建完整备份。
- 使用有意义的快照名称，例如“战役合集启用状态”或“2026-09 人物 Mod 更新前”。
- 恢复前关闭游戏，并确认恢复计划中的新增、禁用和覆盖项目符合预期。
