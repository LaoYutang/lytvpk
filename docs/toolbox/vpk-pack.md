# VPK 打包

“VPK 打包”用于把一个资源目录打包成 `.vpk` 文件。

## 作用

当你已经准备好 L4D2 资源目录时，可以用这个工具生成 VPK，方便放入 `addons` 使用。

源目录应该是 VPK 根目录，也就是 `materials`、`models`、`scripts` 等文件夹的父目录。

## 示例结构

```text
my_mod
├── materials
├── models
└── scripts
```

选择 `my_mod` 作为源目录，而不是选择里面的 `materials`。

## 使用步骤

1. 打开“工具箱”。
2. 点击“VPK 打包”。
3. 选择源目录。
4. 选择输出位置，或直接输出到当前 `addons` 目录。
5. 等待打包完成。

如果输出到 `addons`，完成后会刷新 MOD 列表。

## 拖拽文件夹打包

把 Mod 源目录拖进应用窗口时，应用会先扫描内容。根目录包含 `materials`、`models`、`scripts` 等资源结构，且目录中没有已有 VPK 时，应用会自动打包并将结果放入当前 `addons` 目录。如果同时发现已有 VPK，选择“打包资源目录”会在打包时排除已有 VPK。其他拖拽情形见 [导入与拖拽](/features/import-drag-drop#拖入文件夹)。

## 注意事项

- 源目录层级要正确。
- 文件名建议只使用常见英文、数字、下划线或短横线。
- 打包前确认目录中没有无关的大文件。
